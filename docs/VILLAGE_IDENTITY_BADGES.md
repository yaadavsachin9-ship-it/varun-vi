# Village Identity Badges

VARUN uses local geographic emblems in the Monitoring Sector panel. They are intentionally not presented as official municipal seals. Each emblem is a compact visual identity derived from the village's real river basin, gorge, headwater, terrace, forest, or highland setting in the seeded demo data.

Examples:

- Raini: Rishiganga glacier and confluence setting
- Tapovan: Dhauliganga valley
- Mana: Saraswati headwaters and high-altitude border setting
- Govindghat: Alaknanda confluence
- Jomsom: Kali Gandaki gorge and high, dry Mustang landscape
- Pokhara: Seti Gandaki gorge and Phewa Valley water system
- Darchula: Mahakali gorge and Api Himal region
- Melamchi: monsoon valley and watershed

The badge artwork is generated from local Lucide icons and CSS so the dashboard does not depend on remote image hosting or unverifiable stock photography.
